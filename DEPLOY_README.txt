شبّة أبو البسم — تجهيز للنشر على Render
النوع: Web Service / Node
Build Command: npm install
Start Command: npm start
Environment variable: ADMIN_KEY = رمز سري طويل تختاره
الموقع يدعم بث الحالة بين الأجهزة طالما الخادم شغال. الحالة محفوظة في الذاكرة فقط وتُفقد عند إعادة تشغيل الخدمة.
Twitch: اتصال IRC الحالي من صفحة الستريمر. Kick/TikTok: الربط الحقيقي غير متاح بعد؛ الخانات تجريبية فقط.
يتطلب مستودع Git متصل بـ Render للنشر. لا تضع ADMIN_KEY في مستودع عام.
